# Personal Portfolio

This repository contains the source code for my personal developer portfolio website.

The portfolio is built as a **single-page application using plain HTML, CSS, and JavaScript**, with a focus on clean structure, responsive layout, and a professional presentation of projects and skills.

---

## ✨ Features

- Single-page, tab-based navigation
- Clean and minimal UI with modern styling
- Responsive layout for desktop and mobile
- Smooth section transitions
- Dedicated sections for About, Skills, Projects, and Contact
- Focus on backend-oriented development projects

---

## 🛠️ Tech Stack

- **HTML** – Semantic structure  
- **CSS** – Modern layout, grid, and responsive design  
- **JavaScript** – UI interactions and section switching  

---

## 📌 Purpose

This portfolio is designed to:
- Showcase my projects and technical skills
- Present my learning journey in backend development
- Serve as a professional online presence for internships and opportunities

The emphasis is on **clarity, structure, and real-world applicability**, rather than excessive animations or frameworks.

---

## 🚀 Current Status

The portfolio is actively evolving as I:
- Add new projects
- Improve backend integrations
- Refine UI and UX details
